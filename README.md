# Wheel of Fortune Configurator

This program allows you to create and customize your own wheel of fortune with various features. You can:

- Choose the number and probability of options on the wheel
- Add images from your IOS device and select the color for each option
- Save and load data from a JSON file
- Adjust the size of the wheel, the displayed images and the duration of the spin animation
- Use keyboard shortcuts for convenience
